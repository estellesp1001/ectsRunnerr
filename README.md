# 🎓 ECTS Runner

Ένα παιχνίδι όπου ο παίκτης συλλέγει ECTS, αποφεύγει εχθρούς και ολοκληρώνει 8 εξάμηνα για να πάρει πτυχίο.

## 🎮 Χαρακτηριστικά

- 8 διαφορετικά εξάμηνα με μοναδικό visual theme
- Σύστημα ζωών (κάθε 2 εχθροί → +1 ζωή)
- Dash, διπλό άλμα
- 8 soundtracks (ένα ανά εξάμηνο)
- 4 ηχητικά εφέ
- Particle effects (καπνός, σκόνη, λάβα)
- Level select menu
- In-game pause menu

## 🕹️ Χειριστήρια

| Πλήκτρο | Λειτουργία |
|----------|-------------|
| ← → | Κίνηση |
| SPACE | Άλμα (διπλό) |
| SHIFT | Dash |
| 1 ή ESC | Pause menu |
| ENTER | Έναρξη / Επόμενο |
| R | Restart |
| M | On/Off ήχου |
| ↑ ↓ | Ένταση ήχου |
